Reasoning-task evaluation matrix

Slots → KU types (the data has no separate Problem / Material / Condition fields): Problem = context + question · Method = method · Material / Condition = procedure · Result = result · Claim / Hypothesis = claim (+ question). "given" = only these KU types stay visible in the target's own paper; neighbouring papers are unchanged. Retrieval tasks: balanced MRR of the true KU among ~100 same-type KUs of related papers (×chance ≥ 1.5 = solved). Consistency: balanced accuracy of supports vs contradicts on hidden claim–evidence edges (chance 0.5). Intervention: relative shift = how much the predicted result moves when the condition / method is swapped for another paper's, compared with the gap between two unrelated queries (0 = ignores it); "toward donor" = share of swaps that move the prediction toward the donor paper's actual result (chance 50%).

Paired benchmark (protocol v2: evaluation audit fixed)

Every saved model and comparison system re-scored, without retraining, on one shared question set: the same questions, 100-candidate pools, counterfactual edits, consistency pairs and intervention donors. Ties count half (mid-rank). Average = mean of forward, design, abduction (balanced MRR) and consistency (balanced accuracy), in %; per question, seeds are averaged first; 95 % intervals from a paired bootstrap over the shared questions (consistency pairs resampled by paper). Consistency: JEPA inverse head; embedding systems: probe on their own vectors; LLMs: summed log-probability with a threshold tuned on train pairs; AUC is threshold-free. Intervention: gain in the donor result's reciprocal rank after swapping in the donor's procedure (not in the average). The best JEPA is chosen on validation.

Leaderboard 1 · Reasoning benchmark (main)

The five reasoning tasks on the test split (same queries for every row). Candidates are on-topic: wrong answers come from the papers with the most similar problem, plus counterfactual edits of the true result / claim / method / procedure (direction reversed, negated, number changed, and for experiment design key terms or a sentence substituted from a topic-matched paper). "Beats its counterfactuals" = how often the true answer outranks each edit (chance 50%). Retrieval tasks: MRR ÷ chance (≥ 1.5× = solved). Consistency: balanced accuracy of supports vs contradicts (chance 50%, solved ≥ 65%). Intervention: when the condition (procedure) is swapped for another paper's, does the prediction move toward that paper's actual result (chance 50%), and how much does it move (relative shift; solved: ≥ 0.3 and ≥ 60% toward). Reasoning index = mean of the five scores on one × chance scale (consistency and intervention ÷ 0.5), macro-averaged over canonical research domains (each domain weighs the same, so Physics and Computer Science cannot dominate); the micro index over all queries and the worst domain are shown next to it. Ranked by the macro index.

Safety and reliability

The model ranks findings and judges evidence; it never writes text. The risks are about being trusted when it is wrong: fooled by meaning-reversing edits, shortcuts instead of reasoning, unequal quality across research fields, biased or over-confident judgements. Each check gets pass warn fail against fixed limits (shown under each column). Created by sci-jepa safety <results folder> (add --models for the checks that need the trained models).

Risk card: is it safe for scientists to rely on this model?

The model ranks findings and judges evidence for scientists; it writes no text and takes no actions. So the risks of chat assistants (harmful text, refusal jailbreaks, deception, sandbagging) do not apply, and are not scored. What matters is being trusted when it is wrong. The checks are grouped into eight risk areas (R1–R8), each with the question a scientist would ask, how it is measured, and the standard it follows (NIST AI Risk Management Framework, HELM, and the method behind each check).

Scorecard: one row per system, one column per risk area; a cell shows the worst flag among that area's checks (hover for the values). model = needs the GPU model check, not run = not scored on the shared questions yet. Values carry 95 % intervals (bootstrap over test queries; Wilson when only totals are stored).

All raw checks per system (test split, mean over seeds)

Robustness: share of edited copies (direction / negation / number / substitution) ranked below the true answer, chance 0.5. Worst-domain gap: how much lower the weakest research field scores than the average. Label gap: |recall of "supports" − recall of "contradicts"|: a large gap means the system mostly answers one way. Identity probe: how well the model's vectors identify the source paper (a shortcut when high). Structure reliance: accuracy lost when every typed graph edge is removed (near 0 = the graph is not used). False accept: a wrong candidate also passes the 0.80 similarity rule. Later papers: drop on papers after the encoders' training cutoff (n/a when every test paper is later).

Checks per trained model

Calibration: expected calibration error (ECE) of the supports / contradicts probability (0 = a 90 % answer is right 90 % of the time). Selective prediction: forward-prediction Hits@1 on all queries vs only the 40 % the model is most confident about. Paraphrase stable: the true result keeps its rank (±1) when reworded without changing its meaning. Prefers paraphrase: the reworded truth scores above a meaning-reversing edit.
